# CLI practice files

All data is fictional. This folder is the working directory used in the slides.

## Start on Windows

1. Extract zip using Extract All in File Explorer.
2. Copy the entire cli-practice folder into your Windows user home folder. In Git Bash, cd ~ then pwd shows that location.
3. If cli-practice already exists, rename your existing folder before copying this fresh pack. Keep the original ZIP as a reset copy.
4. Launch Git Bash and run: cd ~/cli-practice
5. Run pwd and ls -la to confirm the folder.

## Folder contents

- documents: populated text files, including a name containing a space.
- logs: application and access logs for investigation.
- archive: an older application log for comparison.
- backup: a destination for copies.
- outputs: a destination for generated reports.
- .practice-info: a dot-prefixed file visible with ls -a.

## Practice goals

Locate the workspace. Read users.txt. Copy and rename a file. Find text files. Identify ERROR lines. Save an error report. Count errors and Admin users. Read help. Delete only a copy.

## Reset

Extract a fresh copy of the original ZIP. Reports and copies change search results, so use a fresh pack when comparing initial file counts.
